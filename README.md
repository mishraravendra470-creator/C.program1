# Student Marks Management System

## About
This is a beginner-friendly C programming project developed for a first-year college semester.

## Features
- Enter student name
- Enter roll number
- Input marks in five subjects
- Calculate total marks
- Calculate percentage
- Display PASS or FAIL result

## Programming Language
C Programming

## Concepts Used
- Variables
- Arrays
- For Loop
- If-Else Statements
- Input and Output

## How to Run
1. Download the main.c file.
2. Open it in a C compiler.
3. Compile and run the program.
4. Enter student details and marks.
